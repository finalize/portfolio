## 直したこと

`sharp` の high 脆弱性を `package.json` の `pnpm.overrides` に `sharp: "^0.35.4"` を追加して修正した（内容は PR #42 と同じ）。

PR #42 は2026-09-09分の点検で同じ修正を出していたが、`claude/daily-2026-09-09` ブランチへの2回目以降の push が `pull_request` の `synchronize` イベントを発火させ、CI / Claude Review / Dependabot auto-merge の3ワークフローが揃って `action_required`（要承認）のまま止まり、`mergeStateStatus` が `BLOCKED` になっていた。今回、空コミットで push し直して再トリガーを試みたが、同じ3ワークフローが再び `action_required` になり改善しなかった（PRオープン後の push は毎回 `action_required` になるという issue #21 のパターン通り）。

そのため、issue #21 で分かっている回避策（PR番号を事前予測し `pr:` を書いた状態で1回の push だけで完結させる）を使い、ブランチを新規に作り直して本PRとして提出した。マージ後、重複する PR #42 はクローズする。
