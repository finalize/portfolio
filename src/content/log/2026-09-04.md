  `pnpm audit`（全体）は完走し、4件の high 脆弱性（`fast-uri`）を検出した。
  `pnpm list fast-uri --prod` で本番依存には含まれないことを確認済み。
- `pnpm outdated`: メジャー更新は `typescript` 6.0.3 → 7.0.2 のみで、既存 issue #3 で追跡中のため変更なし。
  `astro`・`wrangler` の minor/patch 更新は Dependabot の対象。
- `pnpm build`: 警告なく成功（31ページ生成）。
- リンク: `dist/` 内の内部リンクはすべて実在。外部リンクもすべて 200（npmjs.com の 403 のみ対象外）。
- `astro.config.mjs` の `site` と `public/robots.txt` の Sitemap 行は一致。
- `pnpm run check:contrast`: すべての組み合わせが基準を満たす。
- alt 属性・見出し階層・meta description に欠落なし。

## 直したこと

`fast-uri`（`@astrojs/check` → `@astrojs/language-server` → `yaml-language-server` → `ajv` 経由の
devDependency）に4件の high 脆弱性（GHSA-5jgf-p345-68v8 ほか、IDN/IPv6 正規化まわりのホスト混同・SSRF）があった。
本番依存には含まれず型チェック用ツールチェーン止まりだが、`package.json` に
`pnpm.overrides` で `fast-uri: "^3.1.7"` を追加してパッチ済みバージョンに固定した。
`pnpm check` と `pnpm build` が通ることを確認済み。修正後は `pnpm audit` で脆弱性 0 件。

## 直さずに残したこと

- `typescript` のメジャー更新（issue #3 で追跡中、変更なし）。
