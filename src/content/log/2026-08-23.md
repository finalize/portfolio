## 直したこと

ライトテーマの `--accent`（`src/styles/global.css`）が背景 `--bg`（`#eef1ee`）に対してコントラスト比 **4.46:1** で、このリポジトリが基準としている 4.5:1 をわずかに下回っていた。`#1a7f37` → `#1a7e37` に1段階だけ暗くして **4.52:1** にした。

`--accent` はプロンプト行のパス表示・ナビの現在ページ・フッターリンクのホバー色など、実際に読まれるテキストに使われている。

## 点検結果

- `pnpm audit --prod` / `pnpm audit`: 脆弱性なし
- `pnpm build`: 警告なく成功
- リンク: 内部・外部とも切れなし
- `astro.config.mjs` の `site` と `public/robots.txt` の Sitemap 行: 一致
- alt 属性 / 見出し階層 / meta description: 問題なし

## 直さずに残したこと

`typescript` 6.0.3 → 7.0.2 のメジャー更新。TypeScript 7 はプログラム用 API を同梱しておらず（対応は 7.1 予定）、`pnpm check` が使う `astro check` が動かなくなる可能性がある。issue #3 に詳細を残した。
